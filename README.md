# PdfDesk

A fast PDF viewer and page organizer for Windows on ARM, modeled on PDF-XChange Editor's viewing and
Organize features. Native ARM64 (.NET 10 WPF + MuPDF), personal use, local git repo, no remote.

## Install

```powershell
pwsh -File install.ps1            # builds publish\win-arm64\PdfDesk.exe, installs to %LOCALAPPDATA%\Programs\PdfDesk
pwsh -File install.ps1 -Uninstall
```

Installs one self-contained ARM64 `PdfDesk.exe` (no .NET needed), Start Menu and Desktop shortcuts, a PDF document
icon, and "Open with" entries for .pdf/.xps/.epub/.cbz. To make it the default: Settings › Apps › Default apps ›
PdfDesk. Icons are generated by `python -I assets/make-icon.py`.

## Using it

- **Windows 11 look**: Mica, document tabs in the title bar (Snap Layouts kept), light/dark/system theme (Ctrl+,).
- **Start page**: open or combine files, or drop them anywhere; recent files show a first-page preview.
- **Reading**: continuous / single / two pages / two pages with cover; a floating pill for page and zoom; Ctrl+wheel or
  touchpad pinch zooms at the pointer, touch screens pinch and pan; fit width / fit page; dark pages for night reading
  (hue-preserving); full screen (F11); each file reopens where you left it.
- **Side rail**: Pages (thumbnails), Bookmarks, Search; F4 hides the pane.
- **Find** (Ctrl+F): floating find box with match case / whole words; Search pane (Ctrl+Shift+F) lists every hit.
- **Tools**: hand (H), select text (T, double/triple-click for word/line), snapshot to clipboard (G); links (asks
  before opening anything but http/https/mailto); Back/Forward (Alt+←/→).
- **Organize pages** (Ctrl+Shift+O): a grid of large pages; click / Ctrl / Shift to select, arrows to move, drag to
  reorder, hover a page to rotate or delete it, double-click or Enter to open it, Esc when done.
- **Page edits** (all undoable; every edit shows a toast with Undo): rotate, delete, insert from file or blank,
  extract (new tab, one file, or a file per page), split (by count, ranges, or bookmarks), move, duplicate, reverse,
  crop/uncrop, combine files. Drag thumbnails onto another tab to copy pages; drop PDFs onto thumbnails to insert them.
- **Command palette** (Ctrl+K): every command, recent files, or a page number. **Shortcuts**: F1.
- Print (shrinks oversized pages, auto-rotates; renders in the background), export pages as PNG/JPEG, document
  properties (title/author/subject/keywords editable), password-protected PDFs. Also views XPS, EPUB, CBZ, FB2, images.

## Layout

| Path | What |
|---|---|
| `src/PdfDesk.Core` | `PdfEngine` (MuPDF: render, text, links, outline), `PageEditor` (PDFsharp page edits, bytes in → bytes out), `DocumentSession` (bytes + undo snapshots), `PageText`, `PageRange` |
| `src/PdfDesk.App` | WPF UI. `Viewer/PageViewer.cs` is the virtualized page view; `DocumentTab` holds panes; `Organize.cs` / `FileActions.cs` are the commands |
| `tests/PdfDesk.Tests` | `dotnet test tests/PdfDesk.Tests` |

Dev check without touching the screen: `PdfDesk.exe file.pdf --script steps.txt` runs UI steps off-screen and
writes snapshots (see `DevScript.cs`). Set `PDFDESK_DATA` to a temp folder so the run saves settings there instead of
leaving your own settings untouched and unsaved.

## Known limits

- Page edits go through PDFsharp, which rewrites the whole file, so its size can change. Digital signatures are
  invalidated by any page edit, as in every editor.
- Editing pages of a password-protected PDF needs its owner (permissions) password; opening it with the user
  password allows viewing, printing and copying only. Edits are saved without the password protection
  (PdfDesk warns before the first edit).
- Annotations, form filling, OCR, redaction and text editing are not in v1.
